# 1. Purpose

The purpose of the visualisation stage is to communicate the main analytical findings from Project 01 clearly and efficiently.

The visualisations will show:

- differences between EU countries;
- changes between 2023 and 2025;
- relationships between GDP per capita and digitalisation indicators.

The charts will be designed for both:

1. portfolio presentation; and
2. professional data-analysis demonstration.

---

# 2. Visualization Principles

The visualisations will follow these principles:

### Accuracy

Charts must represent the underlying data without distortion.

### Clarity

Each chart should communicate one primary analytical message.

### Comparability

Where countries are compared, the same measurement definitions and units must be used.

### Transparency

Source datasets and relevant definitions will be documented.

### Appropriate interpretation

Correlation will be described as association rather than causation.

### Accessibility

Charts should use readable labels, sufficient contrast and clear units.
